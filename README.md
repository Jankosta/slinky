This project is a physics simulation created in Trinket.io using Python and VPython. It models a system of five blocks connected vertically by springs (a simplified representation of a slinky) under the effects of gravity, spring forces, and drag.

The simulation begins with the spring system attached to a fixed point, allowing the blocks to oscillate and approach equilibrium. When the **Z key** is pressed, the top spring is released and the entire system enters free fall while the blocks continue interacting through the remaining springs.

Graphs display the position and velocity of each block over time, as well as the simulated and theoretically expected center-of-mass motion. The project demonstrates how internal spring forces affect the motion of individual objects while the motion of the system's center of mass is determined by the net external force acting on the system.
